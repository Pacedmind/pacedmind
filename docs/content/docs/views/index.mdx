PacedMind shows the same tasks, activities and sessions in several views. Each view answers one question; the sidebar lists them in this order, with both calendar views under **Calendar**.

| View | Answers |
| --- | --- |
| **[Inbox](/views/inbox)** | What still needs a place? Tasks without an area or project. |
| **[Today](/views/today)** | What's overdue, due or planned today, and what's on the calendar? |
| **[Assigned to me](/team-workspaces#assigned-to-me)** | What's assigned to me, in my own areas and my team workspaces? Only with a team workspace or a task assigned to you. |
| **[Upcoming](/views/upcoming)** | What's coming in the next 14 days, and how are the projects doing against their target dates? |
| **[Calendar: month](/views/calendar)** | What falls on which day? Move tasks between days by dragging. |
| **[Calendar: week](/views/calendar-week)** | How does the week fit into my hours? Activities, auto-planned focus blocks and agent sessions. |
| **[Timeline](/views/timeline)** | How does the work spread over weeks? Bars for tasks and projects, and dependencies. |
| **[Projects](/views/projects)** | Which areas and projects exist, and how far along are they? |
| **[Roadmap](/views/roadmap)** | When does each project run, and in which order do a project's tasks come? |
| **[Sessions](/views/sessions)** | Which agent sessions are running, and which wait for review? |

**Settings**, including **Computers**, has its own menu: see [Settings](/settings) and [Computers](/settings#computers).

Below the views, **Areas & projects** groups each area's projects under its heading. Collapse a group with its arrow, add a project with its **+**, or drag the heading to change the group order. See [Areas and projects](/concepts/areas-and-projects#order-and-select-several).

## What the views share

* **The details panel.** In most views, clicking a task opens its details on the right; <kbd>Esc</kbd> closes them. See [The task details panel](/tasks/task-details). Two views work differently: in the month calendar, a click opens the task's menu, which has **Open task**; in **Sessions**, a click selects the session, and **Open task** opens the task in its project's list.
* **Live updates.** An open view checks for changes every few seconds and refreshes when something changed, for example when an agent updated a task over MCP or a session finished. Hidden windows don't check; they catch up when shown again.
* **Links with the task selected.** A task link, such as one from the command menu, opens the view with the task's details already open.
* **Back and forward.** The arrows in the header (<kbd>Alt</kbd>+<kbd>Left</kbd> and <kbd>Alt</kbd>+<kbd>Right</kbd>) move through the views visited.
* **Themes.** Every view follows the dark or light theme chosen in the sidebar or in **Settings → Appearance**.

## Counts in the sidebar

| Item | Counts |
| --- | --- |
| **Inbox** | Open tasks without an area or project. |
| **Today** | Open tasks due today or earlier, or planned for today. |
| **Assigned to me** | Open tasks assigned to you. |
| **Sessions** | Finished sessions waiting for review. |

A count disappears at zero.
